# Informational

Websites for companies whose business type is informational — a brochure site
that says who the company is, what it does and how to reach it. No cart, no
checkout, no account.

| Template | Stack | Port | Notes |
| --- | --- | --- | --- |
| [white-theme](white-theme/) | Next.js 15 · App Router · TypeScript | 4400 | Single page — header, hero slider, sections, footer |

Each template is its own app. Add a second theme as a sibling folder rather than
a flag inside an existing one.
