2. Golden rules

  1. API-first, no hard-coded data. Anything a client shows comes from a backend endpoint; templates never invent tenant content.
  2. Constants are the catalogue. Enums, feature keys, transition maps and limits live in Aj-Smart-Biz-Backend/src/constants/index.js. Never duplicate a list elsewhere — mirror it in TypeScript types with a “Mirrors X in the API” comment.
  3. One decision, one function. Entitlement (functionality.service), quota (quota.service), service state, offer status (isOnOffer), enquiry target — reuse them; never re-derive in a controller or UI.
  4. Guard at the module. Add routes inside the right module (/admin, /super-admin, /theme, /website); never add ad-hoc auth.
  5. Tenant from token. Use resolveCompanyId(req); never accept companyId from an admin's body.
  6. Server-side money. Prices, totals, discounts computed on the server.
  7. Snapshots for history; soft delete for everything else.
  8. Explain why. The codebase uses long comments that state business reasons and rejected alternatives — keep that style.
  9. Themes are triplets. Logic changes in themes/ are copied verbatim to all three designs; only CSS differs.

3.2 Model

'use strict';
const { DataTypes } = require('sequelize');
const { STATUS, STATUS_VALUES } = require('../constants');

/** Why this table exists, what it is not, and the rules it keeps. */
module.exports = (sequelize) =>
  sequelize.define(
    'CompanyWarehouse',
    {
      id: { type: DataTypes.INTEGER.UNSIGNED, primaryKey: true, autoIncrement: true },
      companyId: { type: DataTypes.INTEGER.UNSIGNED, allowNull: false },
      branchId: { type: DataTypes.INTEGER.UNSIGNED, allowNull: true },
      name: { type: DataTypes.STRING(150), allowNull: false },
      sequence: { type: DataTypes.INTEGER, allowNull: false, defaultValue: 0 },
      status: { type: DataTypes.ENUM(...STATUS_VALUES), allowNull: false, defaultValue: STATUS.ACTIVE },
      createdBy: { type: DataTypes.INTEGER.UNSIGNED, allowNull: true },
      updatedBy: { type: DataTypes.INTEGER.UNSIGNED, allowNull: true },
    },
    { tableName: 'company_warehouses', indexes: [{ fields: ['company_id'] }, { fields: ['status'] }] }
  );

Register in models/index.js: require, associate (Company.hasMany(X, { foreignKey: 'companyId', as: '…', onDelete: 'CASCADE' }) + X.belongsTo(Company)), and add to the exported db. Use SET NULL / constraints:false for history references. No unique indexes on business keys — check in the service.

3.4 Controller

const list = asyncHandler(async (req, res) => {
  const companyId = resolveCompanyId(req);
  const { page, limit, offset } = getPagination(req.query);
  const where = mergeWhere({ companyId },
    req.query.status ? { status: req.query.status } : null,
    buildSearch(req.query.search, ['name', 'code']));
  const result = await db.CompanyWarehouse.findAndCountAll({
    where, order: getSort(req.query, ['name', 'created_at'], [['sequence', 'ASC']]),
    limit, offset, distinct: true });
  return paginated(res, result, { page, limit }, 'Warehouse list fetched successfully');
});

const create = asyncHandler(async (req, res) => {
  const companyId = resolveCompanyId(req);
  await functionalityService.assertGranted(companyId, FUNCTIONALITY.WAREHOUSE);
  const row = await db.CompanyWarehouse.create({ ...req.body, companyId, createdBy: req.auth.id });
  return created(res, 'Warehouse created successfully', row);
});
  • Errors: throw ApiError.badRequest('Readable reason', errors?), .notFound, .forbidden, .conflict.
  • Responses: success(), created(), paginated() — messages “<Label> created successfully”.
  • Ordered card lists: use cardResource.factory.js; platform masters: crud.factory.js.

3.6 Route and mount

const router = require('express').Router({ mergeParams: true });
const may = (action) => requirePermission('warehouse', action);
router.get('/', may('canView'), validate(schema.list), controller.list);
/** Before `/:id`, or "reorder" would be read as an id. */
router.patch('/reorder', may('canEdit'), validate(schema.reorder), controller.reorder);
router.post('/', may('canCreate'), validate(schema.create), controller.create);
router.put('/:id', may('canEdit'), validate(schema.update), controller.update);
router.patch('/:id/status', may('canEdit'), validate(master.statusBody), controller.toggleStatus);
router.delete('/:id', may('canDelete'), validate(master.idParam), controller.remove);
module.exports = router;

Order: guard → validate → handler. Literal paths (/summary, /reorder, /analytics, /quota) before /:id. Mount tenant routes in routes/myCompany.routes.js (under /admin/company) or modules/admin/admin.routes.js; super-admin in modules/superadmin; public in modules/theme.

3.7 Menus, permissions, Swagger

  • Add { name, slug, icon, route, sequence, parent? } to seeders/defaultMenus.js; add to MENU_INHERITS_PARENT if it is part of its parent's screen; to MENU_FUNCTIONALITY if plan-gated. Boot inserts it and grants every Company Admin role.
  • New upload folder → FOLDERS in middlewares/upload.js.
  • Swagger: routes are auto-scanned; add @openapi prose blocks and register request schemas in SCHEMA_SOURCES (src/docs/openapi.js).
  • Backfills: an idempotent ensureX() step in seeders/bootstrap.js.

4. Angular consoles

4.1 Conventions

ComponentsStandalone (no NgModule), ChangeDetectionStrategy.OnPush, inject() in fields, data loaded in the constructor (no ngOnInit).
Statesignal(), computed(), effect(); signal inputs/outputs (input(), output()); .subscribe({ next, error }).
TemplatesBuilt-in control flow only: @if, @for (x of xs; track x.id), @empty, @switch. Separate .html via templateUrl.
FormsReactive, fb.nonNullable.group; <app-field-error>; touchAll(form) on invalid submit; cleanPayload().
StylesGlobal design system in src/styles.scss (tokens + primitives: .card .btn .table .badge .modal .field .input…). Component styles inline styles: [...] using var(--…) only; budget 4 kB warn / 8 kB error.
HTTPOnly through ApiService (unwraps envelope). Errors: toast.error('Could not …', messageOf(err)).
Namingkebab-name.component.ts/.html; *-list, *-detail, *-manager (Company Details editors); selectors app-*.
Modelsinterface X extends AuditFields; string-literal unions for enums; as const arrays.
TestsNone present; schematics skip spec files.

6. Recipe: add a new feature end to end

Example: a sellable “Suppliers” feature for the company workspace that also shows on the website.

  1. Constants — add FUNCTIONALITY.SUPPLIERS + FUNCTIONALITY_CATALOGUE entry; any enums as X/X_VALUES.
  2. Model — models/companySupplier.model.js; register and associate in models/index.js.
  3. Validator — validators/supplier.validator.js (create/update/list).
  4. Service (if rules) — services/supplier.service.js.
  5. Controller — controllers/supplier.controller.js with resolveCompanyId, assertGranted on writes.
  6. Routes — routes/supplier.routes.js; mount under /admin/company/suppliers with requirePermission('suppliers'); super-admin nested mount if needed.
  7. Menu — defaultMenus.js row + MENU_FUNCTIONALITY.
  8. Public payload (if on the website) — add features.suppliers in functionality.service/public.controller, null unless active; add a NAV_PAGES row if it is a page.
  9. Swagger — @openapi blocks + SCHEMA_SOURCES.
  10. Admin UI — model, service, features/suppliers/supplier-list.component.*, route with permissionGuard, *appCan, <app-feature-gate>.
  11. Super Admin UI — nothing for the plan form (it reads the catalogue); add screens only if operators need them.
  12. Themes ×3 — SiteFeatures type + FALLBACK_COMPANY null; lib/suppliers.ts resolver; SuppliersSection.tsx + per-theme .module.css; page with guard chain.
  13. Verify — run the API on SQLite, exercise endpoints (Swagger), ng build both consoles, npm run typecheck + build each theme.
  14. Document — README section, docs/schema.dbml, these docs.

7. Formatting, naming and comments

AreaRule
Indentation2 spaces, UTF-8, final newline, trim trailing whitespace (.editorconfig).
Quotes / widthSingle quotes; Prettier printWidth: 100 in Angular apps (HTML with angular parser).
Backend filescamelCase with suffix: .model.js .validator.js .controller.js .service.js .routes.js; 'use strict' first line.
DatabaseModel PascalCase singular; table snake_case plural, company_ prefix for tenant tables; columns snake_case (raw SQL uses snake_case).
KeysMenu slugs kebab-case; functionality keys snake_case; constants UPPER_SNAKE.
CommentsJSDoc paragraphs explaining why; section dividers /* ---- name ---- */; route-order notes.
MessagesUser-facing errors are full sentences the UI can show verbatim.
