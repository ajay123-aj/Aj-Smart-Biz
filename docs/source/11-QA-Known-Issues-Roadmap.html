1. Current verification

  • The project README records 188 API checks over five passes (both logins, provisioning, quotas, permission matrix, soft-delete cascade and restore, dashboards, uploads, ICO validation, domain resolution, guard rails, cross-tenant isolation) and 63 browser checks against production bundles of both consoles.
  • These suites were run from a scratch directory (SQLite + puppeteer-core) and are not committed to the repository.
  • No unit tests exist in any application; Angular schematics are configured with skipTests; there is no linter configuration.
RiskWithout committed tests, regressions in business rules (proration, stock, entitlement) are caught only manually.

6. Roadmap

Now (stabilise)

  • Fix K1–K2 and README drift
  • Commit API + E2E suites; CI on PRs
  • SMS gateway behind hasSmsGateway()
  • Backups and restore drill

Next (monetise)

  • Payment gateway for platform invoices and tenant orders (webhook → paid)
  • Email/WhatsApp notifications for renewals and orders
  • Self-serve sign-up from the product site
  • Refresh tokens

Later (scale)

  • Sequelize migrations
  • Object storage/CDN for uploads
  • More website designs per business type
  • Data export & privacy tooling
  • Persistent job queue for AI and reports
