1. Engine and conventions

EngineMySQL (utf8mb4, timezone +05:30). SQLite supported for local work (DB_DIALECT=sqlite).
Schema managementsequelize.sync({ alter: true }) on boot (DB_SYNC_MODE = alter | force (dev only) | none). There are no migration files.
Primary keysid INT UNSIGNED AUTO_INCREMENT; BIGINT for lead_visits and marketing_lead_visits.
NamingTables snake_case plural, explicit tableName; tenant tables prefixed company_. Model attributes camelCase → columns snake_case (underscored: true).
Common columnsstatus ENUM('active','inactive'), created_by, updated_by, created_at, updated_at, deleted_at.
Soft deleteAll tables paranoid except company_functionalities, company_invoice_items, company_stock, company_stock_movements, lead_visits, marketing_lead_visits.
UniquenessBusiness keys (company code, slugs, warehouse code…) are checked in services, not by unique indexes, because soft-deleted rows would block reuse. Exceptions: company_domain.domain; composite (company_id, key) on company_functionalities (MySQL only).
Branch scopingWebsite content tables carry nullable branch_id: NULL = company-wide; a branch row overrides it.
JSON columnsPlan features/functionalities, plan snapshot, product images/highlights/specs, service highlights/days, settings blobs, blog tags.
AssociationsDeclared only in src/models/index.js.

14. Delete semantics

  • CASCADE from companies and branches for owned content (sliders, cards, products, stock rows).
  • SET NULL / no constraint for records of money and history: orders, service leads, order items and stock movements referencing products, invoice pointers.
  • Snapshots copied onto orders, order items, invoices, service leads and subscriptions so history survives edits and deletes.
  • Deleting a category promotes subcategories and un-categorises products in one transaction (done by hand because a soft delete never fires ON DELETE SET NULL).

15. Schema change process

  1. Edit or add src/models/<name>.model.js; register and associate in src/models/index.js.
  2. Restart the API: alter-sync adds tables and columns. Backfills go in an idempotent ensureX() step in src/seeders/bootstrap.js.
  3. Back up production before deploying a model change; alter-sync can rebuild tables on SQLite and must never run with force in production (boot refuses it).
  4. Update docs/schema.dbml and this document.
