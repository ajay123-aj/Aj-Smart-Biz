5. CI/CD pipelines

Each service has two GitHub Actions workflows triggered by pushing to a dedicated branch.

WorkflowTriggerWhat it does
<service>-live.ymlpush to <service>-live or manualBuild with buildx and push only. Tags <service>-1.0.<run> and <service>-live.
<service>-deploy.ymlpush to <service>-deployJob 1 (ubuntu-latest): build, push <service>-deploy-1.0.<run>, output digest. Job 2 (self-hosted runner on the server): validate /opt/aj-smart-biz/<svc>.env (API_URL set, unquoted, no trailing slash, no CRLF), pull by digest, docker run -d --restart unless-stopped --network aj-smart-biz --env-file … -p HOST_PORT:APP_PORT, wait ≤ 2 min for healthy, roll back to the previous image on failure, prune.
docker-publish.ymlpush to dev_live touching backendBackend image tagged aj-smart-biz-backend-dev_live.
deploy-nginx-domains.ymlpush to nginx-domain-liveCloudflare A records → sync domains/*.conf to /etc/nginx/conf.d/managed-*.conf → nginx -t + reload (rollback on failure) → certbot --nginx.

Services: aj-smart-biz-backend, -admin, -supper-admin, -technology, -theme-default, -theme-midnight, -theme-atelier.

7. Onboarding a tenant domain

  1. In the Super Admin (company → Domains) or Company Admin (Company Details → Domains), add the bare host, optionally pinned to a branch.
  2. Add a vhost in nginx-domains/domains/<host>.conf on branch nginx-domain-live, proxying to the chosen design's port (4400/4500/4600). Push — DNS, nginx and TLS are applied by the workflow.
  3. For domains not in the Cloudflare zone, the tenant points an A record to the server IP first.
  4. Open the site; the middleware resolves the tenant from X-Forwarded-Host.

8. Operations runbook

SituationAction
Website shows “Service unavailable”API unreachable from the container: check docker ps, API health (/api/v1/health), network aj-smart-biz, API_URL in the env file.
Website shows “Company not found”Domain row missing/inactive, company inactive, or vhost not forwarding X-Forwarded-Host.
Website shows holding pageNo running subscription — check Company Plans; reactivate or assign a plan.
Plan did not expire/start on timeSuper Admin → Company Plans → Run expiry check (POST /super-admin/subscriptions/run-due); check API logs for the hourly sweeper.
Deploy failedWorkflow rolls back automatically; read job 2 logs (env file validation, health timeout).
Uploads missing after redeployEnsure the backend container mounts a persistent volume at /app/uploads.
Too many indexes (MySQL ER_TOO_MANY_KEYS)Boot drops duplicate key_N indexes before alter-sync; restart the API.
BackupsSchedule mysqldump of the database and an archive of the uploads volume; take one before any model change is deployed.
Rotate secretsChange JWT secrets (signs everyone out), super-admin password, Docker Hub token; update server env files.
