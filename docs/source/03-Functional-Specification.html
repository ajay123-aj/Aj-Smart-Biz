1. Functionality catalogue

Sellable features are listed once, in FUNCTIONALITY_CATALOGUE (Aj-Smart-Biz-Backend/src/constants/index.js). A plan grants keys; the tenant switches them on; the platform serves them while the plan runs.

3. Company Admin workspace (:4300)

Audience: a company's admins. The login screen brands itself from the domain (/theme/branding). After sign-in, /auth/me returns the user, a permission map and the menu tree; the sidebar renders exactly that tree. First sign-in with a generated password forces a password change.

Special states

  • ServiceUnavailable — the API cannot be reached.
  • CompanyNotFound — the domain belongs to no active tenant.
  • PlanNotice (holding page) — plan expired, suspended or never assigned; noindex.

Cart behaviour

  • Basket held in the browser (ajsb.cart.v1) as line snapshots.
  • Submission sends product ids and quantities; the API returns order number, total and WhatsApp/payment hand-off.
  • Basket off → “Order now” sends one product at once. Out-of-stock or non-orderable products show no button.

6. Cross-cutting behaviour

BehaviourSpecification
ListsPaged (10/25/50/100), search debounced 350 ms, sortable columns, status filter; envelope meta {total, page, limit, totalPages, hasNext}.
Status toggleEvery entity active/inactive via PATCH /:id/status.
DeleteConfirmation dialog; soft delete; restore where offered.
ReorderWhole ordered list sent in one PATCH /reorder.
UploadsImage MIME only; favicons validated as real ICO; per-company storage limit; replaced files deleted.
ErrorsToast with the API's message; field errors under fields; 401 → sign out; server down → full-screen retry.
Dark modeBoth consoles toggle light/dark, remembered per browser.
TrackingWebsites send a beacon per page view (device id, session, UTM, device, optional geolocation) via their own /api/track.
